Overview
CYBERSPINE is an indie software project that modernizes classic snake mechanics by combining vector mathematics, physics simulation, and dynamic combat elements. The engine is built around cursor-tracking vertebrate segment physics, custom particle visual effects, multi-phase boss fights, and robust collision detection algorithms.

The primary engineering goal of this project is to implement low-level game loops, custom vector mathematics, and Object-Oriented Programming (OOP) design patterns to build a clean, highly optimized 2D game architecture.

🚀 Key Features
Vector-Based Segment Physics: Smooth, articulate creature movement following the cursor using procedural segment tracking.

Boss Mechanics & Combo System: Multi-phase boss encounters with dynamic attack patterns and combo animations.

Custom Visual Effects: Custom particle systems, dynamic color palettes, and real-time visual feedback for high combat game feel.

Self-Collision & Food Logic: Optimized algorithms handling growth mechanisms, item collection, and self-collision checks.

Flexible Configuration System: Modular architecture allowing seamless tuning of performance and gameplay parameters.

🛠️ Tech Stack & Architecture
Language: Python

Framework / Engine: Pygame

IDE: Visual Studio Code

Codebase Scale: 1,500+ Lines of Code (Modular Architecture)

The architecture decouples core game logic into dedicated components for state management, input handling, rendering, and vector physics calculations.
